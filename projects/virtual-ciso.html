Virtual CISO Kit

A Claude Project that works as a senior security and governance adviser to the accountable CISO. It builds and maintains a risk-based program organized on NIST CSF 2.0, and I can take it to any organization to start a program from a proven baseline.

Domain
Security governance, risk, and compliance
Frameworks
NIST CSF 2.0, ISO/IEC 27001:2022, SOC 2, PCI DSS 4.0.1, NIST SP 800-53, FedRAMP, GovRAMP, GDPR, Canadian Protected B
Delivered as
Portable Claude Project with eight operating commands
Designed around accountability: the adviser cannot certify compliance, accept risk, or approve policy. Those decisions are routed to a named human approver every time.

What it does

  • Onboards an organization in small batches of questions and builds a context register that separates known, unknown, and assumed facts, with sources
  • Drafts approval-ready policies, standards, procedures, and plans, each with ID, owner, approver, requirements, exceptions, evidence, monitoring, and review cycle
  • Maps controls many-to-many across frameworks and rates each link as identical, partial, related, conflicting, or not mapped, with a confidence level
  • Produces readiness assessments, POA&Ms, risk registers with inherent and residual ratings, and decision-ready CISO briefings

Safeguards

  • No control is marked Implemented, Tested, or Compliant without objective evidence naming the owner, period, and reviewer
  • Every requirement cites the exact source, version, and control reference. When the text can't be checked, it says "Verification required" and shows how to verify
  • Keeps verified facts, user claims, source requirements, interpretations, and assumptions visibly separate
  • Treats uploaded documents and web pages as untrusted reference material, never as instructions
  • Separates control design, implementation, and operating effectiveness when planning tests
